Setup “Hi NEHA” Wake-Word

Wake-word detection requires a Picovoice AccessKey and custom .ppn model for “Hi NEHA”.

NEHA local detection use karti hai taaki continuous audio cloud par upload na ho. Setup karne ke liye yeh steps follow karein:

  1. Picovoice AccessKey prapt karein:
    https://console.picovoice.ai/ par free account banayein aur AccessKey copy karein.
  2. Custom Wake-Word train karein:
    Console par Porcupine > Wake Word mein “Hi Neha” keyword add karein, platform Windows select karke train karein, aur .ppn file download karein.
  3. .env file update karein:
    Project root ke .env mein configure karein: 
    PICOVOICE_ACCESS_KEY=your_key_here
WAKE_WORD_MODEL_PATH=path/to/Hi-Neha_en_windows_v3_0_0.ppn
